#R #Statistiques #Algèbre Avril 2025

Modélisation Prédictive
Valeur Foncière

Construction d'un algorithme de régression linéaire "from scratch" en R natif sur les ventes immobilières des Deux-Sèvres.

Contexte du projet

Ce projet s’inscrit dans le cadre d’une étude prédictive à partir d’un jeu de données réel sur les ventes de maisons et d’appartements (2023-2024). L’objectif académique majeur : interdiction d'utiliser des bibliothèques externes ou les fonctions natives (`lm` ou `predict`).

Objectifs & Contraintes

L'enjeu était de concevoir mathématiquement le modèle à partir du jeu d’entraînement (variables explicatives + prix de vente), puis de l’appliquer pour prédire les valeurs foncières sur le jeu de test, en recréant manuellement les calculs matriciels.

Réalisation Technique

Méthodologie "From Scratch"

  • Analyse descriptive des variables (distribution, moyenne, biais).
  • Traitement et encodage manuel des variables catégorielles.
  • Calcul manuel des coefficients (Inversion et Produits Matriciels).
  • Application du modèle via une fonction prédictive maison.

Livrables & Résultats

  • Code R complet de la lecture des données à la prédiction.
  • Document d’analyse détaillant le processus de modélisation.
  • Fichier `prediction.csv` généré avec les valeurs estimées.
  • Évaluation de la performance (Somme des carrés des résidus).
