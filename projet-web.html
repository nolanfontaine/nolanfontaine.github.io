Application Web
Pêches Électriques

Création complète d'un portail web dynamique connecté à une base de données MySQL pour exploiter des jeux de données OpenData.

Contexte du projet

Dans le cadre du module "Technologies Web", j'ai dû concevoir de A à Z une application permettant de visualiser et de gérer un jeu de données massives issu de l'OpenData français (data.gouv.fr). Le choix s'est porté sur les résultats des pêches électriques en Basse-Normandie, avec la mission de rendre cette information accessible via un navigateur web.

Objectifs & Valeur ajoutée

L'objectif n'était pas seulement d'afficher des données, mais de bâtir une véritable architecture Full-Stack : un Backend robuste (PHP/MySQL) gérant le CRUD (Création, Lecture, Modification, Suppression) sécurisé, et un Frontend dynamique intégrant des indicateurs statistiques complexes via JavaScript et jQuery (diagrammes circulaires, cartes, densité d'espèces).

Réalisation Technique

Méthodes mises en œuvre

  • Conception UML : Réalisation du diagramme des cas d'utilisation pour cibler les fonctionnalités clés.
  • Base de données : Import scripté et conception du modèle relationnel sous MySQL.
  • Développement Backend : Logique serveur en PHP (requêtes SQL dynamiques, variables de session, sécurité de connexion).
  • Développement Frontend : Interface HTML/CSS responsive et intégration asynchrone jQuery/JS.

Production Finale

  • Un portail Web avec authentification gérant l'accès sécurisé aux données.
  • Une page d'administration permettant l'import de nouveaux datasets et la gestion des tables métiers (CRUD).
  • Un "Tableau de Bord" interactif : carte géographique des stations, et graphiques temporels/massiques par espèce.
  • Un compte-rendu d'architecture technique détaillant la conception de la base de données et de l'interface.
