Application Web
Spoti-Lolo

Création d'une plateforme Full-Stack de numérisation et de gestion de bibliothèque de partitions musicales avec interface dynamique et analyse OCR.

Contexte du projet

Dans le cadre du module "Technologies Web", j'ai développé "Spoti-Lolo", une application web complète de gestion de bibliothèque musicale. L'objectif était de concevoir une plateforme permettant aux musiciens d'importer, de stocker, de lire et d'organiser leurs partitions (fichiers PDF) de manière intuitive, à la manière des grandes plateformes de streaming actuelles.

Objectifs & Valeur ajoutée

Le défi majeur de ce projet était l'interactivité. Plutôt que de faire une application classique nécessitant de recharger la page à chaque action, j'ai mis en place une véritable architecture "Single Page Application" (SPA). Toutes les actions de CRUD (modification, suppression, ajout aux playlists) communiquent avec la base de données de manière asynchrone (AJAX) pour offrir une expérience utilisateur fluide et moderne.

Réalisation Technique

Méthodes mises en œuvre

  • Backend PHP (PDO) : Création de mini-API internes (endpoints d'édition, d'ajout et de suppression) pour sécuriser et séparer la logique métier de l'affichage.
  • Frontend Dynamique : Utilisation de Vanilla JavaScript (API Fetch) pour modifier le DOM en temps réel sans utiliser de bibliothèques lourdes comme jQuery.
  • Algorithmique Web : Implémentation d'un moteur de recherche instantané en JS et d'un système de bascule de vues (Grille / Liste) sauvegardé en localStorage.
  • Analyse de fichiers : Intégration d'un module Drag & Drop permettant l'import de multiples PDF, relié à un script d'analyse OCR pour la reconnaissance de texte.

Production Finale

  • Un tableau de bord adaptatif affichant les partitions triables par artiste, année, et date d'ajout.
  • Un système de fenêtres modales interactives (créées en CSS/JS pur) pour modifier les métadonnées de la musique ou gérer ses playlists.
  • Une zone de dépôt (Drag & Drop) visuelle couplée à une interface de chargement (Spinner) lors du traitement asynchrone des PDF.
  • Une gestion sécurisée des bases de données MySQL (jointures, clés étrangères entre Artistes, Partitions et Playlists).
