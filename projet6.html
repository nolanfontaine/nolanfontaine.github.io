#SQL #Python Avril 2025

Conception Base de Données
Sel Marin

Conception, implémentation et interface Python pour informatiser la gestion d'une coopérative de sel de l'île de Ré.

Contexte du projet

Dans le cadre de cette SAÉ, nous avons répondu à une problématique réelle d'une coopérative de sel marin de l’île de Ré souhaitant informatiser sa gestion. Ce projet consistait à concevoir une base de données complète modélisant les entrées de sel par les sauniers, les traitements, et les ventes.

Objectifs & Développements

Le but était de créer un modèle conceptuel (MCD/MLD) et un script SQL complet pour MySQL. Nous avons également conçu une interface Python avec la librairie Tkinter permettant de visualiser et manipuler les données brutes issues de fichiers CSV.

Réalisation Technique

Méthodologie

  • Analyse des besoins à partir du cahier des charges client.
  • Modélisation des données avec Looping (MCD → MLD).
  • Création de scripts d’importation de données (CSV → MySQL) via Python.
  • Développement d’une interface graphique Tkinter.

Livrables Finaux

  • Fichier MCD Looping et script SQL de création de la base.
  • Scripts d’insertion des données réelles de l’année 2023.
  • 10 requêtes SQL complexes pour l’analyse des stocks/ventes.
  • Interface Tkinter ergonomique connectée à la BDD.
